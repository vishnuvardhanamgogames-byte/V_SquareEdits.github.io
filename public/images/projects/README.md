# Project Images

Place your project thumbnail images here.

## Expected filenames (update `index.html` src attributes accordingly):
- `project-01.jpg` — Cinematic Trailer Edit
- `project-02.jpg` — Multifandom Cinematic Edit
- `project-03.jpg` — Motion Graphics Advertisement
- `project-04.jpg` — Social Media Campaign

## Current state
Project cards currently use **CSS gradient placeholders** defined in `css/style.css`:
- `.gradient-01` — deep blue / purple
- `.gradient-02` — dark teal
- `.gradient-03` — dark crimson
- `.gradient-04` — dark olive

To replace with real images, add an `<img>` tag inside `.project-image` or set a CSS `background-image` on the gradient class.
